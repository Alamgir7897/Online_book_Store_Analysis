# Online Book Store Data Analysis using SQL

## Project Overview
This project focuses on analyzing an Online Book Store database using SQL and PostgreSQL. The main objective is to extract meaningful insights from book sales, customer information, inventory, and order records using SQL queries.

The project involves creating database tables, importing CSV datasets, and performing basic as well as advanced SQL queries to analyze business performance and customer purchasing behavior.

## Database Structure
The database consists of three main tables:

1. **Books:** Contains book details such as Book ID, Title, Author, Genre, Published Year, Price, and Stock.
2. **Customers:** Stores customer information, including Customer ID, Name, Email, Phone, City, and Country.
3. **Orders:** Contains order details such as Order ID, Customer ID, Book ID, Order Date, Quantity, and Total Amount.

## Analysis Performed

### Basic Analysis
- Retrieved books belonging to the Fiction genre.
- Found books published after 1950.
- Filtered orders within a specific date range.
- Calculated the total stock of available books.
- Identified the most expensive book.
- Retrieved orders with quantities greater than one.
- Found orders with a total amount above a specified value.
- Listed all available book genres.
- Identified books with the lowest stock.

### Advanced Analysis
- Calculated the total number of books sold for each genre.
- Found the average price of books in the Fantasy genre.
- Identified customers who placed at least two orders.
